Native POST-only browser administration for immutable app history and atomic activation.

Configuration

Operator-supplied Program 0 endpoint and protocol adapter are required once the native ABI is frozen. This build fails closed when no tested capability adapter is injected.

Credentials are decrypted locally in this browser. The access secret is never sent over the network, stored in public releases, or logged.

Applications and release history

Shows every discovered application and every ready historical release. Activation performs one bounded compare-and-swap on the active release pointer only (O(1) in versions and asset bytes). No release assets or application data are copied or migrated.

Select “Inspect manifest” on a release to view its historical manifest details.
